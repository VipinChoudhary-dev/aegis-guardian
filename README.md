## 🔧 Configuration

### MetaMask Setup

1. **Install MetaMask**
   - Visit [metamask.io](https://metamask.io/)
   - Download browser extension
   - Create or import wallet

2. **Add Polygon Amoy Testnet**
   - Open MetaMask
   - Click network dropdown
   - Select "Add Network" → "Add manually"
   - Enter details:
     ```
     Network Name: Polygon Amoy Testnet
     RPC URL: https://rpc-amoy.polygon.technology
     Chain ID: 80002
     Currency Symbol: POL
     Block Explorer: https://amoy.polygonscan.com
     ```

3. **Get Test Tokens (FREE)**
   - Visit [faucet.polygon.technology](https://faucet.polygon.technology/)
   - Select "Polygon Amoy"
   - Enter your wallet address
   - Click "Submit"
   - Receive free POL tokens

## 🌟 Key Features Explained

### Danger Zone Detection
The map displays 8 danger zones in Bengaluru with different risk levels:
- **High Risk (Red)** - Avoid after 8 PM
- **Medium Risk (Amber)** - Exercise caution
- **Low Risk (Green)** - Generally safe

When you drag the marker into a danger zone, you'll receive an instant alert with:
- Zone name
- Risk level
- Description
- Safety recommendations

### Emergency System
Two types of emergency activation:

**1. Manual Emergency**
- Hold button for 5 seconds
- Visual countdown displayed
- Location automatically shared
- Release anytime to cancel

**2. Stealth SOS**
- Shake device 10 times rapidly
- No visible indication
- Silent alert to authorities
- Perfect for dangerous situations

### NFT Rewards
Gamification encourages exploration:
- Visit real tourist locations
- Check in on the map
- Receive unique NFT badge
- Build your collection
- Share achievements

### Digital ID Security
Your ID is secured through:
- Blockchain verification
- QR code authentication
- Encrypted storage
- No personal data on-chain
- Instant verification by authorities
